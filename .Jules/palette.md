## 2026-05-07 - Dropdown Accessibility Roles\n**Learning:** When adding ARIA attributes to custom dropdowns using native checkboxes, using `aria-haspopup="listbox"` or `role="menu"` is incorrect because it implies strict keyboard navigation management (like ArrowUp/ArrowDown). Instead, using only `aria-expanded` and `aria-controls` with a stable ID is the proper way to handle Disclosure widgets for screen readers.\n**Action:** Only use `role="menu"` or `role="listbox"` when full custom keyboard navigation is implemented. For simple native input disclosures, stick to `aria-expanded` and `aria-controls`.
