## 2024-03-24 - Modal Backdrop Accessibility
**Learning:** Adding `aria-hidden="true"` to a modal's backdrop `div` when it also wraps the modal's content (acting as a parent container) is a severe accessibility regression. It causes the entire modal and all its children to be invisible to screen readers, entirely defeating the purpose of other accessibility improvements like `role="dialog"`.
**Action:** When implementing modal backdrops, never apply `aria-hidden="true"` to a wrapper element that contains the modal content itself. If a backdrop must be hidden from screen readers, it must be implemented as a separate sibling element to the dialog container, rather than a parent wrapper. Always verify ARIA tree structure when modifying modal DOM hierarchies.
