## 2026-07-04 - Adding aria-labels to icon-only buttons\n**Learning:** This application extensively uses icon-only buttons (like Edit/Delete in data grids, and tools in the header) which were previously relying only on standard HTML `title` tooltips. For screen readers, these buttons lacked proper semantic description, reducing accessibility.\n**Action:** When working on generic components or data grids, verify that icon-only buttons are given robust `aria-label` attributes that preferably reuse the existing localization keys mapping to their `title` or tooltip.
